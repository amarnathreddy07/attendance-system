AttendIt Architecture

Local-first teacher attendance management system

React 18 Dexie.js / IndexedDB Vite 5 Tailwind CSS PWA + Service Worker Zero Backend

Five-layer architecture from UI to infrastructure. No server, no cloud — 100% client-side.

2. Technology Stack

Frontend

  • React 18.3 — Functional components + hooks
  • React Router 6.26 — HashRouter for SPA routing
  • Tailwind CSS 3.4 — Utility-first styling

Data Layer

  • Dexie.js 4.0 — IndexedDB wrapper
  • dexie-react-hooks — Reactive useLiveQuery
  • IndexedDB — Browser-native NoSQL DB

Build & Dev

  • Vite 5.4 — Dev server + production build
  • @vitejs/plugin-react — Fast Refresh
  • PostCSS + Autoprefixer

PWA & Offline

  • vite-plugin-pwa 1.3 — Manifest + SW generation
  • Workbox — Precaching + offline fallback
  • autoUpdate registration type

Deploy

  • GitHub Actions — CI/CD pipeline
  • GitHub Pages — Static hosting
  • Node.js 20 runtime

Language

  • JavaScript (ES2022) with JSX
  • ES Modules ("type": "module")
  • No TypeScript — pure JS codebase

6. Data Flow (Reactive Round-Trip)

User actions flow down to IndexedDB. Dexie's live query system detects changes and re-renders the UI automatically — no manual refresh needed.

👆
User Action
Click Present / Absent / OD
→
⚡
Component Handler
mark(RECORD_STATUS.PRESENT)
→
📦
Repository
upsertRecord(session, student, status)
→
🔄
Dexie Transaction
Find → Update or Insert
→
💾
IndexedDB
Write persisted to disk
↩ Dexie change detection → useLiveQuery re-fires → React re-renders (progress bar, counters, student card update)
